Glacier Notes Cloud

A self-hosted, multi-user notes web application — an OpenAPI-first monorepo with a Quarkus (Java 21) backend, an Angular frontend, and PostgreSQL persistence.

  • Quarkus 3.37.3
  • Java 21
  • Angular 22.0.7
  • PostgreSQL 18.3
  • Docker Compose
Get started See features

Features

Notes & organization

  • Owner-scoped notebooks, notes, checklists, and labels with archive and trash
  • Sanitized Markdown editing and rendering
  • Ordered checklists with text search and checkbox toggling
  • PostgreSQL-backed full-text search with ownership filters
  • Note version history with preview and restore
  • Image attachments across filesystem, PostgreSQL, or S3-compatible storage, with thumbnails and per-user quotas

Portability & account

  • Portable .glacier.json import/export, desktop-compatible
  • Full account, notebook, or single-note export scope
  • Conflict resolution on import: add as copies, or replace existing by ID
  • Profile and verified email changes, password reset history
  • Self-service account deletion with retention and restoration

Administration

  • User management and invitations
  • Immutable audit event log, exportable as CSV or JSON
  • Instance settings and SMTP status
  • Prometheus metrics on a private management port
  • Environment-gated automated backups with restore verification
  • English and German localization with synced user preferences

Security & operations

  • Opaque session tokens with keyed hashes and double-submit CSRF protection
  • Argon2id password hashing and progressive login throttling
  • Ownership isolation enforced at the repository layer — no cross-owner lookups
  • OWASP dependency scanning and Trivy container image scanning in CI
  • Automated log-hygiene enforcement (content, passwords, and tokens are never logged)
  • Named security-attack-simulation tests: session fixation, token replay, path traversal

Setup guide

1. Local setup (for testing)

Regenerate the OpenAPI-generated contracts, install frontend dependencies, then run the backend and frontend side by side. Backend requires a Docker daemon for Dev Services (PostgreSQL) and a few environment variables. 

# From the repo root
./mvnw -pl backend clean generate-sources
cd frontend && npm ci && cd ..

# Terminal 1 — backend, with required env vars
export GLACIER_BOOTSTRAP_TOKEN=local-bootstrap-token-development-only
export GLACIER_SECURITY_SESSION_SECRET=local-session-secret-development-only
export GLACIER_IMAGE_FILESYSTEM_ROOT=/tmp/glacier-notes-dev-images
./mvnw -pl backend quarkus:dev

# Terminal 2 — frontend (proxies /api to :8080)
cd frontend && npm start
# Open http://localhost:4200

2. Production setup (real use)

Generate real secrets, then build and start the full Compose deployment (Quarkus app image plus PostgreSQL). 

cp .env.example .env
mkdir -p deployment/secrets
openssl rand -base64 36 > deployment/secrets/database-password.txt
openssl rand -base64 36 > deployment/secrets/bootstrap-token.txt
openssl rand -base64 48 > deployment/secrets/session-secret.txt
chmod 600 deployment/secrets/*.txt

docker compose up --build --wait
# Open http://127.0.0.1:8080

# Stop, preserving volumes:
docker compose down
# Stop and delete data permanently:
docker compose down --volumes

3. Running all tests

The full verification loop mirrors CI: backend build and tests, then the frontend contract/lint/build/unit chain, plus the security gates added for the release candidate. 

# Backend — full reactor build and JUnit tests against PostgreSQL
./mvnw verify

# Backend security gates
./mvnw -pl backend org.owasp:dependency-check-maven:check
bash backend/scripts/check-log-hygiene.sh

# Frontend
cd frontend
npm ci
npm run test:repository     # repository/generated-client metadata
npm run check                # Biome format + lint
npm run build:production     # strict Angular production build
npm run test:ci              # Vitest unit suite
npm audit --omit=dev --audit-level=high

# End-to-end (needs a running Compose deployment)
GLACIER_E2E_BASE_URL=http://127.0.0.1:8080 \
GLACIER_E2E_USERNAME=<username> GLACIER_E2E_PASSWORD=<password> \
npm run test:e2e
